## Ход работы

### Шаг 1. Инсталляция и проверка версии Git
На локальном компьютере под управлением операционной системы macOS была произведена установка распределенной системы контроля версий Git. Проверка успешности интеграции утилиты в систему выполнена командой:
```bash
git --version
```
Консоль вернула версию: `git version 2.39.5`.

### Шаг 2. Конфигурация профиля пользователя
Выполнена глобальная привязка учетных данных автора для автоматического логирования создаваемых коммитов:
```bash
git config --global user.name "Афонин С.А."
git config --global user.email "seafonin@example.com"
```

### Шаг 3. Инициализация и фиксация изменений
В локальной рабочей директории `programming-labs` развернут репозиторий командой `git init`. Создана структура каталогов, после чего выполнен первый коммит:
```bash
git add .
git commit -m "Initial commit: create structure and lab_01"
```

### Шаг 4. Публикация проекта на GitHub
На облачной платформе GitHub создан удаленный репозиторий. Выполнено связывание локального хранилища с удаленным сервером под именем `origin`, после чего локальная ветка `main` была вытолкнута в облако с использованием токена доступа Personal Access Token:
```bash
git remote add origin https://github.com
git branch -M main
git push -u origin main
```
