## Ход работы

### Задание
Напишите скрипт, вычисляющий физическую величину по формуле. Все переменные должны быть динамически привязаны к значениям. Вывод результата осуществить с округлением вещественной части до 4 знаков после запятой. Исходные параметры ввести с помощью функции `input()`.

**Вариант:** Сопротивление медного кабеля: \(R = p \cdot L / S\)

### Решение
```python
p = float(input("Введите удельное сопротивление (р): "))
L = float(input("Введите длину кабеля (L): "))
S = float(input("Введите площадь поперечного сечения (S): "))

R = p * L / S

print(f"сопротивление медного кабеля R={R:.4f}")
```

**Вывод программы в консоль:**
```text
Введите удельное сопротивление (р): 0.0175
Введите длину кабеля (L): 150
Введите площадь поперечного сечения (S): 2.5
сопротивление медного кабеля R=1.0500
```
