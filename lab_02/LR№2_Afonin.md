## Ход работы

### Задание
**Анализ гидросистем.** Написать функцию `check_hydro_pressure(p_list, max_p=25.0)`, считывающую замеры давления. Пропускать отрицательные сбойные замеры с помощью `continue`. Функция должна находить максимальное давление и возвращать статус «Безопасно» или «Опасно!», выводя результаты вычислений на экран.

### Решение
```python
def check_hydro_pressure(p_list, max_p=25.0):
    max_pressure = 0
    for pressure in p_list:
        if pressure < 0:
            continue
        if pressure > max_pressure:
            max_pressure = pressure
            
    if max_pressure > max_p:
        status = "Опасно!"
    else:
        status = "Безопасно"
        
    print(f"Максимальное давление: {max_pressure}")
    print(f"Статус: {status}")
    return status

p_list = [12.5, 18.3, -2.0, 24.1, -11.4]
check_hydro_pressure(p_list)
```

**Вывод программы в консоль:**
```text
Максимальное давление: 24.1
Статус: Безопасно
```
